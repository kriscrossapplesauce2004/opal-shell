# Bundled themes

Opal reads only each theme's colours (colors.toml or alacritty.toml), preview.png and backgrounds/. Wallpapers are resized copies.

- Omarchy stock themes (catppuccin … white): https://github.com/basecamp/omarchy, MIT License, see LICENSE-omarchy.
- flexoki-dark: https://github.com/euandeas/omarchy-flexoki-dark-theme (MIT, see flexoki-dark/LICENSE)
- mars: https://github.com/steve-lohmeyer/omarchy-mars-theme (MIT, see mars/LICENSE)
- one-dark-pro: https://github.com/sc0ttman/omarchy-one-dark-pro-theme (MIT, see one-dark-pro/LICENSE)
- oxocarbon: https://github.com/HANCORE-linux/omarchy-oxocarbon-theme (MIT, see oxocarbon/LICENSE)

Community themes without a permissive licence are bundled as colour values only, in ../omarchy-themes.toml.
